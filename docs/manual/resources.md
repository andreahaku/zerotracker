# Resources: learning the M8 workflow

ZeroTracker reads M8 song (`.m8s`) and instrument (`.m8i`) files and follows much of the M8
workflow. Most material written for the Dirtywave M8 therefore applies to ZeroTracker too. The keys
are different: the M8 has 8 buttons, ZeroTracker uses the CardputerZero keyboard. Firmware versions
also differ, so a feature in a recent video may not exist in ZeroTracker yet.

ZeroTracker is an independent project. It is not made, endorsed or supported by Dirtywave. Please
do not send ZeroTracker questions to Dirtywave support.

All links were checked on 18 October 2026. Every video title and channel below was read from
YouTube, not copied from a list.

## Official Dirtywave resources

- [M8 Operation Manual (PDF, last updated 21/04/2026)](https://cdn.shopify.com/s/files/1/0455/0485/6229/files/m8_operation_manual_v20260421.pdf?v=1776791699) — Dirtywave. The reference for every screen, key combination and FX command. Read it first.
- [Resources & Downloads](https://dirtywave.com/pages/resources-downloads) — Dirtywave. The page that always links the current manual and firmware. Use it if the PDF link above goes stale.
- [Dirtywave](https://dirtywave.com/) — Dirtywave. Official site of the M8 tracker.
- [M8Firmware on GitHub](https://github.com/Dirtywave/M8Firmware) — Dirtywave. Firmware releases and the changelog. The changelog tells you which firmware version added a feature.
- [M8 Headless Firmware](https://github.com/Dirtywave/M8HeadlessFirmware) — Dirtywave. Precompiled firmware that turns a Teensy 4.1 into a headless M8, driven from a computer over USB.
- [M8 Headless Setup Guide](https://github.com/Dirtywave/M8Docs/blob/main/docs/M8HeadlessSetup.md) — Dirtywave. How to flash and use the headless firmware.
- [M8 Music Tracker for iPhone and iPad](https://apps.apple.com/us/app/m8-music-tracker/id6806721202) — Dirtywave. The official iOS version of the M8, paid. Its songs and instruments are compatible with the hardware.
- [M8C Remote Display](https://apps.apple.com/us/app/m8c-remote-display/id6746388495) — Dirtywave. Official remote display client for iOS and macOS.
- [M8 Web Display (m8.run)](https://m8.run) — Linked by Dirtywave. Browser-based remote display for a hardware or headless M8.
- [Recommended microSD cards](https://dirtywave.com/pages/recommended-microsd-cards) — Dirtywave. SD cards known to work well with the M8.
- [Dirtywave on YouTube](https://www.youtube.com/@Dirtywave) — Dirtywave. Official channel, including the M8 community meetup recordings, which explain new features as they ship.
- [M8 Meet-up Timestamps](https://sparkling-scallop-8ab.notion.site/Meetup-Timestamps-cb3b675d93a941839f8ab5b7179e9ffe) — Linked by Dirtywave. Topic index for the meetup videos, so you can jump to one feature.
- [Dirtywave Discord](https://discord.gg/dirtywave) — Dirtywave. Official community server, about 16,000 members.

## Written guides and references

- [The M8 Companion](https://cs.uwaterloo.ca/~plragde/flane/TM8C/) — Prabhakar Ragde and Brian Simpson. A free book that teaches the M8 through complete songs. Licence: CC BY-NC-SA 4.0.
- [Open M8 Tips, Tricks, and Findings](https://docs.google.com/document/d/1IpUeR2s9TpkwH9w2lfqfLLkUxLvXcQWipDR046DzOYk/edit) — community (Google Docs). A large collection of tips from M8 users.
- [M8 Tracker Shortcuts, Tips & Tricks](https://sites.google.com/view/m8tracker/) — community. Shortcuts from the manual and forums, sorted by screen.
- [M8Guide](https://github.com/LaurentVitalis/M8Guide) — Laurent Vitalis. A printable, foldable 4-page shortcut guide. No licence stated.
- [M8 Resources](https://notes.nora.codes/m8-resources/) — nora. A short annotated list of guides, videos and tools.
- [M8 Conventions](https://notes.nora.codes/m8-conventions/) — nora. Suggested naming and layout conventions for M8 projects.
- [FM Synth Chords on the M8](https://bit-101.com/blog/posts/2025-04-22/fm-synth-chords-on-m8/) — BIT-101. Written walkthrough of chords with the FM synth.
- [awesome-m8](https://github.com/v3rm0n/awesome-m8) — v3rm0n. A curated list of the M8 ecosystem: clients, tools, instruments, songs. Licence: MIT.

General synthesis, not M8-specific:

- [Ableton Learning Synths](https://learningsynths.ableton.com/) — Ableton. Free interactive course on oscillators, filters, envelopes and LFOs. These blocks are shared by most M8 instrument types.
- [Mutable Instruments Braids manual](https://pichenettes.github.io/mutable-instruments-documentation/modules/braids/manual/) — Mutable Instruments. Explains the oscillator models behind the M8 MACROSYNTH.
